# Employee Hiring & Workforce History | Power BI

A Microsoft Power BI portfolio project focused on exploring **employee hiring information and workforce history** through an interactive business intelligence report.

## Project overview

The purpose of this project is to present employee and hiring-related information in a structured visual format. It demonstrates the use of Power BI to explore workforce data and communicate patterns that may support HR reporting and recruitment analysis.

## Analysis focus

- Employee hiring information and historical workforce records
- Exploration of workforce trends through report visuals
- Interactive filtering and drill-down exploration, where available in the report
- Review of the report structure and underlying data model in Power BI Desktop

> The exact KPIs and dimensions depend on the data model contained in the supplied PBIX report. Review the report pages and model before interpreting or presenting specific findings.

## Repository contents

| File | Description |
|---|---|

## Tools and techniques

- **Microsoft Power BI Desktop** — report development and visualization
- **Power Query** — data preparation, where used in the report
- **DAX** — measures and calculations, where implemented

## Open the project

1. Download or clone this repository.
2. Install and open **Power BI Desktop**.
3. Open `Employee Hiring and History.pbix`.
4. If Power BI reports a missing data source, reconnect the required source or update its path, then refresh the report.

## Portfolio highlights

This project can be used to demonstrate:

- Translating employee and recruitment data into visual reporting
- Exploring historical workforce information
- Building and reviewing an interactive Power BI report
- Understanding the relationship between report visuals, data tables, and calculations
